The first public alpha of coxdragon: OpenAI's official Codex app-server inside an Android app, with a graphical workbench.

## What's here

- Package `cox.dragon` with its own signing key and update channel; the cccodroid shell, terminal, file browser and settings come along.
- **Codex page**: thread list, streaming replies, reasoning summaries, shell cards with live output, patch cards, MCP tool cards, plans, model / reasoning-effort selection, and an approval card for every command that needs one.
- **Official engine**: downloads `codex-app-server 0.166.0` from the `openai/codex` release, checks both the tar and the binary against pinned SHA-256 values, and runs it unmodified.
- **ChatGPT device-code login**: the UI shows the one-time code and opens the verification URL. No key is embedded.
- **Android networking**: the static musl binary gets a loopback-only CONNECT proxy (random password) and a CA bundle. No root, no VPN service.
- **Matching toolchain devkit-2026.11.12**: Termux packages with a same-length prefix relocation to `cox.dragon`, downloaded per module with resume.
- Licensed **AGPL-3.0** as a co-creation project. The upstream cccodroid Apache-2.0 text is kept in `LICENSE-APACHE-2.0`.

## Notes

- Early alpha. The protocol, login, thread and approval paths have been exercised on one Android 17 arm64 device; this is not yet a daily-driver stable release.
- Codex runs as the app's uid with `sandbox: "danger-full-access"` (bubblewrap does not start on most Android devices). Approvals are the only gate: **a command you approve can touch the app-private `~/.codex` credentials**. Read every command card.
- Claude Code is not bundled; you can install it yourself in the terminal if you want it.
- The default build is targetSdk 28; the targetSdk 36 build has not been validated on a device yet.
