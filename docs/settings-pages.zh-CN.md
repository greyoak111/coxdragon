# 分页设置与 Codex 配置（26.1.4 / 26.1.5）

手机设置从分类目录进入单独页面，标题栏、Android 返回和 Escape 逐级返回。平板和桌面保留左侧分类导航，右侧内容单独滚动。分类覆盖提供商、模型与上下文、Codex 行为、指令与项目、权限与审批、技能/MCP、外观与语言、通知、设备与自动化。设备设置再分权限、后台、更新和排障。自动化页管理现有旧任务，仍明确标注实际执行引擎。

提供商分为列表、连接信息、模型目录和模型编辑。模型发现只生成候选，须主动加入目录。切换设置页面保留未保存表单，包括每个提供商的模型草稿；关闭设置清除内存草稿及尚未保存的密钥。保存失败不关闭页面。后续异步响应不覆盖较新的草稿。模型设置与权限入口仍在输入框左侧，模型统计仍在输入框下方。

## Codex 选项

| 页面 | 字段 | 留空行为 |
| --- | --- | --- |
| Codex 行为 | 联网搜索：关闭、缓存、索引、实时 | 继承 Codex / 项目配置 |
| Codex 行为 | 思考摘要：自动、简短、详细、关闭 | 每轮从当前项目的有效配置读取，防止恢复聊天沿用旧摘要偏好 |
| Codex 行为 | 回复详细程度：简洁、适中、详细 | 继承；模型未声明支持时由引擎省略 |
| Codex 行为 | 自动压缩 token 阈值、压缩提示词 | 使用 Codex 默认或项目设置 |
| 指令与项目 | 自定义开发者指令 | 新聊天使用默认指令 |

选项只写入应用私有目录 `coxdragon-codex-options.json`，不改写用户 `config.toml`。输入严格校验，文件原子写入，失败保持内存和磁盘原配置。任务执行、审批、启动或配置读取期间禁止保存；保存后停止空闲引擎，后续请求重新启动并恢复原聊天。

启动参数和线程创建/恢复均传递选项。Chat Completions 适配器无法提供 Codex 托管联网搜索，实际固定为 disabled；搜索偏好可保存以供其他连接使用。“检查生效配置”调用当前项目的 `config/read`，只返回支持字段，不返回提供商密钥或完整配置层。

**自定义指令修改从新聊天生效。** 固定版本引擎恢复聊天时保留历史开发者指令；清空设置不会删除旧聊天历史。这一点在页面中明确说明。模型不支持的摘要、详细程度等参数仍可能被省略或由服务商拒绝，客户端不会将保存成功当成服务商能力验证。

## 兼容依据与验证

使用固定 Codex app-server 0.166.0 JSON schema 的 Config、ThreadStartParams、ThreadResumeParams、TurnStartParams 及 config/read 核对字段，并通过真实引擎进程验证。官方配置参考页面在当前网络返回 403，因此不声称已核验网页最新内容；参考地址：<https://developers.openai.com/codex/config-reference/>。不添加此版本已废弃的 personality 风格选项。

- `node scripts/test-codex-engine.mjs`：71 项通过，覆盖选项严格校验、原子保存失败、运行中保护、线程参数、配置字段白名单及摘要恢复默认。
- `node scripts/test-codex-process.mjs`：Windows 上真实 0.166.0 进程连接隔离的合成接口；验证带引号、换行和反斜线的自定义指令、有效配置、实际摘要请求、清空覆盖、旧聊天历史保留、新聊天清空指令、权限、上下文、工具和失败流。没有真实模型费用。
- `node scripts/test-codex-ui.mjs --screenshots`：真实 Chrome，320/390/820/1440px、中英文；验证分级返回、顶部弹窗优先返回、草稿跨页保留、延迟保存不覆盖新草稿、失败与忙时保护、模型目录与能力模板、有效配置检查、通知、设备、扩展和聊天回归。另在深色模式和 390×430 键盘高度视口检查设置页：标题栏保持可见，内容可滚动，恢复默认和保存按钮可达，Escape 回到分类目录。

## 真机验收与后续修正

2026-11-17，通过无线 ADB 在小米 M2012K11AC / Android 13 验证 26.1.4：

- 分类目录、独立 Codex 行为页及 Android 返回目录均正常。提供商连接信息、模型目录和模型编辑分层显示；CodeFlow 发现 1 个模型，保留请求 ID、models.dev 能力以及 `low / high / max` 强度。权限页保留“询问”。
- 将思考摘要设为 concise、自动压缩阈值设为 64000，保存后重新进入保留设置；“检查生效配置”由实际 Codex 0.166.0 返回 concise、64000，Chat Completions 的 web_search 为 disabled。
- 保存后原聊天继续运行，真实 CodeFlow 返回 `SETTINGS_26_1_4_SAVED_OK`，随后恢复此页默认并保存。重新检查引擎配置：摘要、阈值、回复详细程度、指令和压缩提示词均显示默认，托管搜索仍为 disabled。
- 恢复默认后再次发送，真实 CodeFlow 返回 `SETTINGS_RESTORED_OK`。测试未触发工具调用；保留原提供商、模型、max 强度和询问权限。最后会话累计输入约 71k、输出 608、缓存命中率 86.9%，速度为界面估计值。
