版本号采用 `年份.版本.构建`：`26.1.1` 表示 2026 年、第 1 个版本、第 1 次构建。当前版本是预发布版本。

同一版本的下一次交付递增最后一段，例如 `26.1.2`；新的版本递增中间一段并从构建 1 开始，例如 `26.2.1`。本地测试时重新打包不自动增加构建号。

Android 安装版本以 `android/AndroidManifest.xml` 为准。`versionName` 保持上述格式，`versionCode` 使用 `年份 × 1,000,000 + 版本 × 1,000 + 构建`，因此 `26.1.1` 对应 `26001001`。版本与构建各限 1–999，确保覆盖升级顺序正确。

预发布状态与数字版本号分开记录在 `release.json` 中。`26.1.1` 的 GitHub Release 必须标记为 prerelease，不能仅通过版本号有没有连字符判断。更改版本时同时更新 Manifest、`release.json`、对应的 `android/assets/whatsnew` 说明及内置更新日志。
