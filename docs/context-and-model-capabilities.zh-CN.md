# 上下文与模型能力

手机聊天里的思考摘要与正文间距缩至 6px。SHELL、PATCH、MCP、搜索、图片及其他工具条目默认折叠；用户展开后，流式输出和完成事件不会重新折叠它。展开 SHELL 可分别复制完整命令和完整输出，PATCH 可复制单个补丁，其他工具可复制完整结果 JSON。复制不受屏幕预览截断影响。

输入框下方的“上下文”显示当前聊天最近一次请求的 token 数、上限和占比。用量来自固定版 Codex app-server 的 `thread/tokenUsage/updated`，采用 `last.totalTokens`，不把历史累计费用用量当成上下文占用。上限优先使用引擎报告的 `modelContextWindow`；尚无事件时仅显示模型目录上限，实际用量显示待统计。数据按聊天隔离并在本机保存，最多保留 200 条；重连可恢复。

点开上下文可手动压缩。操作调用引擎的 `thread/compact/start`，原生 `contextCompaction` 条目显示压缩分隔线及进行中/完成状态。压缩期间禁止在同一聊天发送或再次压缩；其他聊天可以继续工作。压缩可能调用所选服务并计费，按钮旁有说明。引擎退出或请求失败会释放锁；恢复到仍在运行的聊天时拒绝压缩。

模型能力优先来自引擎/服务商的模型列表，再用 models.dev 的精确 ID 匹配补充：输入/输出模态、上下文上限、思考支持和明确的思考强度选项。有歧义且无法确定服务商时显示未知，不通过名称片段猜测。预算或开关类型的思考选项不会被虚构成 low/high 等枚举。目录能力是参考信息，第三方转发接口是否实现图片、音频或思考强度仍取决于该接口；识别能力不等于新增媒体上传功能。

第三方模型列表保存在本机，可在模型选择器切换。所选思考强度持久化并传到下一轮请求，Chat Completions 适配器也保留该参数。切换第三方模型需等待引擎空闲，随后重建引擎以应用该模型的上下文上限，原聊天会在下一次请求前恢复。

models.dev 的 MIT 许可随快照和 APK 一起提供。离线快照位于 `gateway/data/models-dev.json.gz`。获取服务商模型列表时，距上次更新超过一天会尝试刷新公开目录；超时最多 4 秒，失败沿用快照，一小时内不重复尝试。公开目录请求不包含 API Key。只有规范化后的公开元数据会写入能力缓存。

维护快照：`node scripts/update-model-catalog.mjs [本地 api.json 路径]`。不传路径时访问 `https://models.dev/api.json`。Windows 与 Linux 打包流程均包含数据、许可和更新校验清单。

验证命令：

- `node scripts/test-codex-engine.mjs`：66 项通过，含元数据覆盖、未知/歧义、缓存重载、离线失败、线程隔离、压缩锁、后台标记与模型切换。
- `node scripts/test-codex-process.mjs`：真实 0.166.0 引擎接本机合成服务，确认 token 事件、手动压缩生命周期、上下文覆盖与 Responses/Chat 的思考强度传递；不调用真实模型。
- `node scripts/test-codex-ui.mjs --screenshots`：真实浏览器检查折叠、复制、6px 间距、压缩成功/失败、背景聊天隔离、320px 弹层及中英文工作流。

## 手机输入框与输出统计

手机输入框采用上下两行：上面输入文字，下面依次为模型设置、权限、加号引用和发送/停止。平板与桌面保留原模型选择布局。

模型设置可选择 ChatGPT 或已保存的第三方提供商、模型、上下文大小和服务声明的思考强度；“配置提供商”进入连接表单。上下文留空采用默认，手填值会保存并在空闲时重启引擎，避免修改运行中的配置。可保存最多 20 个第三方提供商，每个提供商可独立维护最多 100 个模型。

权限模式持久保存，每次创建、恢复聊天和发送都传给引擎：

| 模式 | 沙箱 | 审批 | 审批人 |
| --- | --- | --- | --- |
| 只读 | read-only | never | user |
| 询问（默认） | danger-full-access | untrusted | user |
| 帮我批准 | danger-full-access | untrusted | auto_review |
| 完全访问（红色） | danger-full-access | never | user |

只读禁止提权，需要 Linux 文件沙箱，不支持时拒绝执行。询问和帮我批准依靠 Codex 的原生命令审批，获批命令可访问应用身份有权访问的文件与网络；二者不声称把命令限制在工作区。完全访问取消操作审批，仍受 Android 应用身份约束。运行中或存在待审批操作时拒绝修改权限。

加号或输入 `@` 可选择已安装启用的插件、已启用 skill、MCP 或本地文件。插件以精确 `plugin://<id>` 结构化 mention 发送，skill 以原生 skill 输入发送；MCP 使用明确的服务引用文字，本地文件传路径供模型按需读取。后端重新核验项目清单和文件访问政策，不将密钥目录当作附件。每条消息最多 20 项，引用随当前聊天草稿保存，发送成功才清除。

输入框下方的单行小字依次显示该轮开始时的提供商、模型、强度、输出速度，以及聊天累计输入/输出 token 和缓存命中率。长内容可横向滚动。速度用该轮输出 token 除以首个输出事件到完成的时间，包含期间的工具等待，是估计值；缓存命中率是 `cachedInputTokens / inputTokens`。没有数据时显示 `—`。旧聊天不会根据正文长度伪造历史 token 或速度。

新增验证：专项测试现为 66 项通过；真实引擎验证四种权限参数和只读工具写入被拦截；浏览器验证模型上下文保存、权限失败回退与红色状态、插件/skill/文件实际提交、回复速度与缓存比率。

Android 13 小米 M2012K11AC 真机连接本机合成服务，已验证真实 0.166.0 引擎的会话恢复、token 事件、压缩及工具请求完整性。完全访问模式可执行合成命令。四种权限参数均被引擎接受，但这台手机缺少可用 bubblewrap，只读模式的命令会失败，不能据此宣称只读模式可正常读取。旧 Landlock 模式同样要求 bubblewrap 隔离 app-server 套接字，未采用该兼容开关。询问模式延续 Android 原有命令审批方式，真实测试确认审批前不执行、拒绝不执行、批准后仅执行一次。遇到已知沙箱初始化错误时，命令卡保持结果折叠，并在外侧显示原因和权限入口；不重放命令，也不自动改变所选权限模式。自动审批器的决策依赖所连接模型，合成服务只验证参数和路由，不能代替真实模型审批质量验证。
